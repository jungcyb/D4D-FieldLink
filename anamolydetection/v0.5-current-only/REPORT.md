# v0.5-current-only 실험 보고서 (2026-10-11)

## 결론

AI Hub 전류 데이터만 사용해 **1채널 Isolation Forest 후보 3개**를 실제 학습했다. 다만 독립 모터 시험에서 오경보와 미탐지가 모두 높아 **현장 배포 불가**로 판정한다. "최적화"는 정해진 9개 후보 중 검증 모터의 평균 ROC AUC가 가장 높은 구성을 선택했다는 뜻이며, 좋은 절대 성능을 보장하지 않는다. 기존 v0.4 코드·활성 모델은 바꾸지 않았다.

## 데이터와 방법

- 입력: `outputs/aihub/current_train_2000/features.parquet`, 10,000 기록. 원본은 2,000 Hz, 1초, 동시 측정 전류 3채널이다. 전류 1개 센서 배포 가능성을 보기 위해 **각 채널별 독립 모델**을 만들었다. 진동 데이터는 사용하지 않았다.
- 모터 ID로 분리: 학습 16대, 임계값 보정 6대, 후보 선택 4대, 최종 시험 5대. 어떤 모터도 분할 간 중복되지 않는다. 모델은 학습 모터의 정상 기록만으로 학습한다.
- 특징집합 3종 × 트리/표본 크기 3종 = 9개 설정을 비교했다. 고장 라벨은 검증 모터에서 후보 선택에만 사용했다. 선택 기준은 3채널 검증 ROC AUC 평균. 임계값은 별도의 정상 보정 기록에서 이상 점수 95백분위로 정했다. 시험 기록은 선택·보정에 사용하지 않았다.
- 선택: `amplitude_spectrum`, 128 trees, `max_samples=512`. 검증 ROC AUC: 채널 1/2/3 각각 0.499/0.486/0.456, 평균 **0.480**. 무작위 구분 수준인 0.5에도 못 미친다.

## 독립 시험 (정상 884, 고장 1,310 기록)

| 별도 1채널 모델 | 정상 오경보 | 오경보율 | 고장 탐지 | 고장 재현율 | ROC AUC |
|---|---:|---:|---:|---:|---:|
| current_1 | 211/884 | 23.87% | 401/1,310 | 30.61% | 0.409 |
| current_2 | 382/884 | 43.21% | 512/1,310 | 39.08% | 0.442 |
| current_3 | 145/884 | 16.40% | 563/1,310 | 42.98% | 0.533 |

셋 모두 현장 경보용으로 부적합하다. 고장 유형별 편차도 크며 베어링 고장은 거의 탐지하지 못한다. 보정 모터와 시험 모터의 정상 분포 차이가 커서 목표 보정 오경보율 5%가 시험에서 유지되지 않았다. 시험 결과를 보고 `current_3`를 고르는 행위는 시험 집합 누출이므로 하지 않았다.

### 기존 3채널 기준선과 같은 분할에서의 비교

기존 비교실험의 3채널 전체 특징 IF 설정(64 trees, 최대 256 표본)을 **이번 학습·보정·검증·시험 모터 분할에 동일하게 적용**해 재계산했다. 기존 실험 보고서의 수치와 단순 비교하면 보정 집합이 달라 공정하지 않다.

| 모델 | 검증 ROC AUC | 시험 오경보율 | 시험 고장 재현율 | 시험 ROC AUC |
|---|---:|---:|---:|---:|
| 기존 방식 3채널 IF | 0.409 | 27.38% | 31.91% | 0.409 |
| 새 1채널 IF `current_1` | 0.499 | 23.87% | 30.61% | 0.409 |
| 새 1채널 IF `current_2` | 0.486 | 43.21% | 39.08% | 0.442 |
| 새 1채널 IF `current_3` | 0.456 | 16.40% | 42.98% | 0.533 |

채널 3의 시험 수치는 상대적으로 낫지만, 검증 수치가 낮고 시험에서 채널을 고르면 누출이다. 어느 모델도 안정적 개선을 입증하지 못했다. **학습 정확도**는 정상만으로 학습하는 IF에서 적절한 지표가 아니다. 검증/시험에서는 고장 라벨을 사후 평가에 사용했다.

## SCVU21C0H0512D 연결 조건

[제조사 SCV-U2 계열 페이지](http://seri2b.co.kr/contents/03_product/board.html?board_id=board_product1&mode=view&no=18)는 단일 아날로그 SIGNAL OUT, 정격 전류에 대응하는 ±5 V 출력, DC–20 kHz 주파수 응답을 제시한다. 다만 정확한 주문코드 `SCVU21C0H0512D`의 정격·교정계수는 확인되지 않았다. 센서 출력 전압을 실제 전류 단위로 바꾸는 계수, DAQ 입력 범위·샘플링 속도와 설치 채널을 **확인 전까지 이 모델의 입력에 연결하지 않는다**. 20 kHz는 센서 대역폭이지 DAQ 샘플링 속도가 아니다. AI Hub 원본에는 전류 숫자가 있으나 물리 단위와 해당 센서와의 동등성이 검증되지 않았다. 2,000 Hz/1초/1채널 입력 계약과 달라도 재학습·재보정이 필요하다. 원본 3채널의 번호는 특정 현장 센서 상(phase)에 자동 대응하지 않는다.

## 재현 및 ZIP 사용

```powershell
& .\.venv\Scripts\python.exe .\12_ai_dev\experiments\current_only_v05\train.py --output .\12_ai_dev\outputs\experiments\current_only_v05_repeat
```

ZIP에는 코드, 3개 모델·메타데이터, 상세 결과와 행별 시험 예측, 이 보고서가 포함된다. 입력 데이터 원본은 재배포하지 않는다. `predict.py`는 2,000개의 숫자만 있는 단일 열 CSV를 받아 **연구용** 점수를 출력한다. 패키지 폴더를 `PYTHONPATH`에 추가하거나 저장소의 `12_ai_dev/features.py`와 함께 실행한다. `joblib` 파일은 신뢰할 수 있는 ZIP에서만 로드한다.

후속 작업은 센서 데이터시트/DAQ 설정 확인, 현장 정상 1채널 데이터 확보, 운영 조건별 분리, 독립 고장 시험, 오경보율 재검증이다. 이 전에는 v0.4 운영 모델로 활성화하지 않는다.
