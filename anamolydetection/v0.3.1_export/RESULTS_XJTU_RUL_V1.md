# v0.3.1 XJTU-SY 베어링 RUL 실험

2026-10-10 로컬 Windows CPU에서 실행한 **실험 후보**입니다. 현장 설비의 보장 수명이나 배포 승인이 아닙니다.

## 데이터·라벨

- Downloads의 Google Drive ZIP 3개 안에 RAR 분할 6개가 모두 있었고, RAR5 전체 검증·압축 해제를 통과했습니다.
- 원본 CSV 9,216개, 15개 베어링의 개별 기록 수가 [저자 공개 표](https://biaowang.tech/images/table2.jpg)와 일치했습니다. 2채널, 파일당 32,768점, 25.6kHz, 1분 간격은 [저자 설명](https://biaowang.tech/xjtu-sy-bearing-datasets/)과 첫/전체 파싱 결과로 대조했습니다.
- 라벨은 `(마지막 기록 번호 - 현재 기록 번호) / 60` 시간으로, **실험에서 기록된 run 종료까지 남은 시간**입니다. 신호 1.28초를 수명으로 누적하지 않았습니다. 물리 진동 단위는 CSV에서 확인되지 않아 `source_native_unverified`로 저장했습니다.
- 세 운전 조건마다 베어링 1–3번을 학습(총 9개, 7,032구간), 4번을 검증(3개, 1,679구간), 5번을 최종 시험(3개, 505구간)으로 사용했습니다. 동일 베어링의 구간은 분할을 넘지 않습니다.

## 고정 모델과 결과

`rul.py`의 RandomForestRegressor, 64 trees, 최대 깊이 8, leaf 최소 2, 단일 스레드, seed 42를 사용했습니다. 검증·시험을 보고 하이퍼파라미터를 변경하거나 재학습하지 않았습니다. 특징은 수평/수직 각 14개, 총 28개입니다.

| 분할 | 구간 | 모델 MAE / RMSE (시간) | 학습 RUL 평균값 기준 MAE / RMSE (시간) |
|---|---:|---:|---:|
| 검증 | 1,679 | 8.124 / 10.295 | 7.553 / 8.938 |
| 최종 시험 | 505 | 6.030 / 9.879 | 13.755 / 13.857 |

**검증에서는 단순 기준보다 나쁩니다.** 시험에서 나은 수치만으로 성능이 안정적이라고 결론낼 수 없습니다. 보류 베어링이 분할당 3개뿐이고 시험은 짧은 이력의 비중이 커서 다른 베어링·설비에 대한 일반화 근거가 약합니다. 불확실성 구간도 보정되지 않았습니다. 원본 25.6kHz 프로필과 다른 저속 IMU를 그대로 입력하면 안 됩니다.

출력: `outputs/v0.3.1/xjtu_rul_v1`의 모델·메타데이터·검증/시험 지표. `data/prepared/xjtu_rul_v031`은 원본 분리·검증된 NPZ 캐시입니다. 기존 FEMTO 후보와 학습 데이터를 섞지 않았고 이상 탐지·고장 분류 모델을 새로 학습하지 않았습니다.
